# Contributing

**This project doesn't accept pull requests.** Issues and PRs are closed.

That's a capacity decision, not a statement about your patch. It's maintained by one person
who would rather the code be genuinely useful to you than half-review contributions in the
evenings.

**Fork it instead — see [FORKING.md](FORKING.md).** It's MIT licensed, so your fork is yours
the moment you make it: no CLA, no review queue, no permission needed, no risk of your work
being turned down after you've done it. FORKING.md covers everything hardcoded to this
particular deployment that you'll need to point at your own.

The one exception is **security issues**, which are welcome and should be reported privately
rather than in public — see [SECURITY.md](SECURITY.md).

If you build something with this, I'd enjoy hearing about it: **info@ecoinference.ai**. That's
an invitation, not a support channel.
